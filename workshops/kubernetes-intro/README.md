# Kubernetes Fundamentals Workshop

A hands-on workshop covering Kubernetes basics — kubectl commands, Pods, Deployments with updates and rollbacks, ConfigMaps, Labels, Selectors, and Namespaces.

## Duration

~90 minutes

## Topics Covered

### Level 1 — Getting Started
- Kubernetes architecture overview (Control Plane, Nodes, Pods)
- kubectl CLI basics (cluster-info, get, describe, explain, api-resources)

### Level 2 — Working with Pods
- Running your first Pod imperatively
- Defining Pods with YAML manifests (declarative approach)

### Level 3 — Deployments
- Creating and scaling Deployments
- Rolling updates and rollbacks

### Level 4 — Configuration & Organization
- ConfigMaps (environment variables and volume mounts)
- Labels, Selectors, and Namespaces

## Prerequisites

- Basic terminal/command line knowledge
- No prior Kubernetes experience required

## Features

- Kubernetes Dashboard enabled for visual cluster management
- Pre-built exercise YAML files with inline comments
- Integrated code editor for viewing and editing manifests
- Split terminal for running multiple commands
