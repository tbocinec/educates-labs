# Introduction to Docker

A comprehensive hands-on workshop covering Docker fundamentals from the ground up.

## Workshop Content

This workshop guides you through the core concepts and practical skills needed to work with Docker containers:

1. **Workshop Overview** - Introduction and learning objectives
2. **Docker Basics & Architecture** - Understanding Docker Engine, images, and containers
3. **Running Your First Container** - Pulling and running your first Docker container
4. **Container Lifecycle Management** - Start, stop, restart, and remove containers
5. **Executing Commands Inside Containers** - Interactive shells and one-off commands with `docker exec`
6. **Working with Container Logs** - Viewing, following, and filtering container logs
7. **Environment Variables & Configuration** - Configuring containers with environment variables
8. **Exploring Docker Images** - Inspecting images, layers, tags, and registries
9. **Workshop Summary** - Review of key concepts and next steps

## Technical Requirements

- Docker Engine
- Terminal access
- Internet access (for pulling images)

## Duration

Approximately 60 minutes.
