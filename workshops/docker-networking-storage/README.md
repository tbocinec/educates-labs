# Docker: Networking, Ports & Storage

An intermediate hands-on workshop covering Docker port mapping, volumes, persistent data, and container networking.

## Workshop Content

This workshop builds on Docker fundamentals and dives into three critical areas:

1. **Workshop Overview** - Introduction and prerequisites
2. **Port Mapping & Exposing Services** - Making container services accessible from the host
3. **Volumes & Persistent Data** - Persisting data beyond container lifecycle with volumes, bind mounts, and docker cp
4. **Container Networking** - Bridge networks, DNS resolution, network isolation, and host networking
5. **Cleanup & Best Practices** - Cleaning up resources and production best practices
6. **Workshop Summary** - Review of key concepts and next steps

## Prerequisites

- Basic Docker knowledge (running containers, exec, logs, environment variables)
- Completion of the **Introduction to Docker** workshop is recommended

## Technical Requirements

- Docker Engine
- Terminal access
- Internet access (for pulling images)

## Duration

Approximately 60 minutes.
