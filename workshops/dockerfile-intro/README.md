# Building Docker Images with Dockerfiles

A hands-on workshop covering Dockerfile fundamentals — writing Dockerfiles, understanding image layers and caching, key instructions, best practices, and multi-stage builds for production-ready images.

## Workshop Content

| # | Title | Description |
|---|-------|-------------|
| 00 | Workshop Overview | Prerequisites, objectives, and environment setup |
| 01 | Dockerfile Basics | What is a Dockerfile, key instructions (FROM, RUN, COPY, CMD) |
| 02 | Building Your First Image | Build, tag, and run a custom Nginx image |
| 03 | Understanding Image Layers | Layers, caching, `docker history`, optimizing build order |
| 04 | Dockerfile Instructions Deep Dive | WORKDIR, EXPOSE, ENTRYPOINT vs CMD, ARG, ENV, LABEL, .dockerignore |
| 05 | Best Practices | Minimize layers, specific tags, non-root user, security, cleanup |
| 06 | Multi-Stage Builds | Separate build and runtime stages, dramatic size reduction |
| 99 | Workshop Summary | Review and quick reference |

## Prerequisites

- Familiarity with basic Docker commands (`docker run`, `docker ps`, `docker exec`)
- Completion of the **Introduction to Docker** workshop is recommended

## Duration

Approximately **60 minutes**.
