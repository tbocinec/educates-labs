# Introduction to Docker Compose

A hands-on workshop covering Docker Compose fundamentals for defining and running multi-container applications.

## Workshop Content

1. **Workshop Overview** - Introduction and prerequisites
2. **What is Docker Compose?** - Compose architecture, YAML syntax, and how it relates to Docker CLI
3. **Your First Compose File** - Writing and running a simple compose.yaml
4. **Multi-Container Applications** - Running a web app with a database using depends_on and healthchecks
5. **Essential Compose Commands** - ps, logs, exec, restart, stop, down, and more
6. **Environment, Volumes & Networking** - Configuring services with env files, persisting data, and service discovery
7. **Scaling & Profiles** - Running multiple instances of a service and using profiles for optional services
8. **Workshop Summary** - Review and next steps

## Prerequisites

- Basic Docker knowledge (running containers, images, environment variables)
- Completion of the **Introduction to Docker** workshop is recommended

## Duration

Approximately 45 minutes.
